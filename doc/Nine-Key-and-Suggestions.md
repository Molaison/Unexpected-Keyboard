# 九宫格、剪贴板与界面（2.1.1）

## 现在怎么用

九键上点击 ABC / DEF 等字母组，一个按键代表一个拼音字母。匹配后，候选栏显示
`ni hao`，编辑器的预编辑文字显示 `nihao`，而不是 `64426`。空格选第一候选；
Enter 或点击拼音原文上屏的是当前匹配拼音。选择“你好”后仍可继续选择后半句。
数字编码仅用于内部保留退格位置；明确滑向数字角标或切换数字键盘才直接输入数字。
不能解析的原始输入保留为回退，避免静默丢字。

**候选栏右侧“拼音 ▾”**可直接选择其他读音，不必发现隐藏的长按操作。
候选行右侧箭头展开多行候选，底部“更多”加载后续候选。
空闲时顶部 `9 / 26` 切换布局；九键底部直接切换中英、数字或语音。
原有 26 键布局及高级滑动功能保留。候选栏和编辑行分开，避免长拼音挤压汉字。

## 剪贴板

顶部“剪贴板”始终可见（密码和数字输入框除外）。整张卡片或文字点按即可粘贴，
面板保持打开，方便连续粘贴。☆ 固定、⋮ 全文预览／固定／删除，删除后底部可撤销。
“最近”和“固定”分开；清空需确认，只清最近历史和当前系统剪贴板，不删除固定内容。
固定条目沿用原来的 `pinned_clipboards` / `pinned` 存储，无破坏性迁移。

自动历史记录仍需主动开启。关闭时仍能使用当前非敏感剪贴板，但不自动保存历史。
最近最多 30 条，新安装默认 60 分钟过期；已有过期时间设置保留。历史仅在内存，
重启进程会丢失；固定内容留在本机。单条历史最多 65,536 个字符，总量最多 262,144
个字符。标记为 Android `IS_SENSITIVE` 的新剪贴板内容不进入历史或当前预览；
这依赖复制来源正确标记，不等于能自动识别一切敏感文字。面板不额外请求网络权限。

## 词库改进与边界

保持原有 AOSP 解码器与本机学习文件不变，增加固定版本 Rime Ice 基础＋扩展词库
的九键直查索引，共 882,585 个去重“词＋读音”记录。不是在旧词库数量上简单累加，
也不是整体换成 librime。精确词条可补回被原先 48 条拼音路径 beam 剪掉的读音；
原有 native 解码继续负责整句、分段与已有学习。仅由新索引提供的扩展词不会写入
原生用户词库；目前没有新增神经语言模型、云联想或自动同步词库。

`tools/build_nine_key_lexicon.py` 记录上游 commit 与输入 SHA-256；显式 `--download`
可以重建，平时构建和手机运行无需下载。`assets/pinyin/nine_key.json` 是数量、来源和
二进制校验记录。额外索引约 26.25 MB，使用只读 mmap，不将全部词条转成 Java 对象；
APK 和存储会增大，不能把 mmap 等同于零内存开销。全拼词库未整体替换。

验收中的固定词表 `test/native/nine-key-recall.tsv` 是 seed=20261006、基础／扩展各
40 条符合长度条件的随机样本。样本 recall@256 从 47/80 到 80/80；这不代表首选
准确率、日常输入成功率或商业输入法水平。仍可能需要读音选择或分段选词。

## 外观与原有功能

默认跟随系统的浅／深色现在使用柔和背景、区分功能键、圆角、留白和候选首项强调。
设置 → 外观 → 主题可选“柔和浅色／柔和深色”；用户明确选择的旧主题不被覆盖。
剪贴板、候选栏跟随同一主题。原有豆包语音入口和参数不变。

## 验收入口

- `bash test/native/run-pinyin-tests.sh`：真实 JNI、原生产词库、新 mmap 索引及隐私回归。
- `gradle checkKeyboardLayouts testDebugUnitTest assembleDebug assembleDebugAndroidTest`。
- `bash tools/run-pinyin-instrumentation.sh emulator-5554`：一次性模拟器中的真实触摸、
  编辑器文本、读音选择、剪贴板操作与浅／深色截图；不会调用豆包云端接口。

请看对应 PR 的最终结果，不能把“写有测试”当成“已经通过”。模拟器不替代真机验证。
包名不变；覆盖安装必须签名一致。临时 debug 签名不能承诺覆盖旧版，不建议直接卸载
旧版来解决签名冲突，以免丢失固定剪贴板、设置及用户词库。
