# 九宫格与联想改进（2026-10-05）

## 使用

在中文 26 键键盘上，从 **Shift 向左上滑动 `9/26`** 切换九宫格。
九宫格右侧直接点击 `9/26` 返回。也可以在设置的布局列表中选择
**Chinese (Pinyin, 9-key)**。中英切换仍在 Ctrl 左上角，豆包语音入口不变。
中文九宫格/26 键偏好会保留；密码、数字、邮件地址的保护规则不变。

按一次键代表一个拼音字母，不需要重复点击选字母。例如：

| 按键 | 目标词 |
| --- | --- |
| 64426 | 你好 |
| 94664486 | 中国 |
| 9674494664486736 | 我是中国人 |

候选可以横向滚动；“更多”继续展开。空格选择第一候选，Enter 或点击原文
原样上屏。先选句子的一部分时，剩余数字继续保留。退格逐个删除原始按键，
到达已经固定的词时，再按退格会取消该词的固定选择。

**同一串数字有多个读音：长按候选栏左侧的原文，选择具体拼音。**
需要精确字母时，可以滑向字母角标；数字角标则直接输入数字，不参与 T9。
`v` 表示 `ü`，Shift 左上角的单引号可以分隔音节。

## 联想变化

中文下一词预测使用光标前最多 7 个连续汉字，而不是只使用上次点中的词。
标点、移动光标、切换编辑器与语言会清除不再适用的上下文。上下文仅在内存
中用于本次编辑，不上传、不额外保存；原有本机词库学习尊重编辑器的
`IME_FLAG_NO_PERSONALIZED_LEARNING`。

英文候选从精确匹配、前缀补全、一次编辑纠错各自取候选后统一去重，
按词频、补全长度与纠错代价排序。已识别的完整词始终保留第一位置。
支持首字母大写和全大写，大小写变换不依赖设备默认 Locale。
重复查询复用上次结果，切换词库、编辑器时失效。英文仍是补全/纠错，
本次没有添加 English next-word language model。

## 实现与边界

复用 APK 现有 AOSP/Rime 转换词库，无新增词库下载或网络预测服务。
`NineKeyComposition` 在合法拼音路径上进行 beam search：最多 48 条路径、
24 条候选读音、每条读音最多 32 个词条，最终最多 256 个去重候选。
每段原始输入最多 39 个按键，与现有 native 解码器的边界一致。

这是有界候选搜索，不是穷举所有读音，也不是神经网络语言模型。长句、
低频人名或高歧义输入可能需要分段选词、指定读音或使用角标输入精确字母。
候选词频评分与路径/长度代价属于启发式；测试样例的首选正确不等于全面
输入准确率评测。查询仍在输入线程执行，设备上的触摸测试与延迟要分开看。
